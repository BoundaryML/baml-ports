BAML is a new language that we're actively developing in https://github.com/BoundaryML/baml.

This repository contains package-port experiment results, which we're using to stress test the completeness and correctness of BAML.

Each port experiment result should be stored in `YYYY-MM-DD-{owner}-{repo}/`, based on the source GitHub repo, and in each directory we'll have `baml-findings/` to contain summaries of the port results.
